# 🚗 SGEI - Sistema de Gestión de Estacionamientos Inteligentes
## Universidad Tecnológica del Perú - Sede Piura

---

## 📋 Descripción del Proyecto

El **Sistema de Gestión de Estacionamientos Inteligentes (SGEI)** es una solución tecnológica desarrollada para la UTP Sede Piura, cuyo objetivo es automatizar y optimizar la gestión de los 200 espacios de estacionamiento del campus.

El sistema permite a estudiantes y docentes:
- Visualizar disponibilidad en tiempo real
- Reservar espacios de manera anticipada
- Recibir notificaciones automáticas

Y a los administradores:
- Supervisar la ocupación
- Generar reportes
- Configurar reglas y tarifas
